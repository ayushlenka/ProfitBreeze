# ProfitBreeze 

**ProfitBreeze** is a full-stack web app designed to help resellers maximize profits when selling on **StockX** and **GOAT**.  
Built with **React, Express.js, MongoDB, Node.js, TailwindCSS, and OpenAI GPT-4**.  

Launched in Summer 2024, ProfitBreeze reached **400+ active users** within its first months.


## Features
- **Profit Calculators** – Compare fees and margins between StockX and GOAT
- **Exchange Rates** – Accurate Calculations using the Open Exchange Rates API
- **Google OAuth** – Seamless authentication and personalized user settings  
- **AI Chatbot** – GPT-4 powered assistant for reseller questions & support  
- **Rate Limiting** – Express middleware prevents abuse and ensures stability  
- **Responsive UI** – TailwindCSS styling for clean and scalable design  


## Tech Stack
**Frontend:** React, TailwindCSS  
**Backend:** Node.js, Express.js  
**Database:** MongoDB (Mongoose ODM)  
**Authentication:** Google OAuth 2.0 + JWT  
**AI:** OpenAI GPT-4 integration
